# Phase 0 spike

Throwaway exploration scripts proving the core pipeline idea works before any real app or pipeline code exists. Not production code — nothing here gets imported by `pipeline/`. If something here proves out, it gets rewritten properly as a real pipeline stage, not moved as-is.

Checkpoints (see planning notes for full detail):
0. Environment sanity check
1. Separation quality, by ear (Seven Nation Army, Friction)
2. Transcription quality
3. Tab quality
4. Does trimming to just the riff help?
5. Second data point (Friction)
